## 怎么投递

1. 点开对应 Issue，读完 JD；
2. 按 Issue 里 **职位详情** 写的联系方式投递（最快的路径）；
3. 或者直接在 Issue 下留言（中英文都行），写明岗位编号 + 你的背景，我会跟进。

建议附上简历（可以是脱敏简历），或者简单介绍下工作年限 + 学历 + 工作经验等信息。

## 这个仓库的规则

- ✅ 公开仓库，任何人可以 **看岗位、留言、提 PR 改错别字**；
- 🔒 但 **只有仓库 owner (@miaozmaio) 可以发布岗位**，其他人发的 Issue 会被自动关闭；
- 📋 岗位必须符合 [**发布规则 ISSUE_RULES.md**](https://github.com/miaozmaio/hr-open-roles/blob/main/ISSUE_RULES.md)，不符合的会被自动告警并标记「发布失败」。

发布入口：[新建岗位 Issue](https://github.com/miaozmaio/hr-open-roles/issues/new?template=job-posting.yml)
